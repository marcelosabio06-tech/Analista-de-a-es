# Analisador de Ações da B3 (Swing Trade)

Aplicativo interativo desenvolvido em Python para análise técnica de ações negociadas na B3.

## Ações Suportadas
* PETR4.SA
* VALE3.SA
* ITUB4.SA
* BBAS3.SA
* WEGE3.SA

## Como Executar no VS Code

1. Abra o terminal no VS Code (`Ctrl + '`)
2. Instale as dependências:
   ```bash
   pip install -r requirements.txt
